# IsOS 0.x 实现里程碑

[English](../../../docs/isos/maintenance/roadmap.md) · [架构](../design/system_cn.md) · [节点目录](../layers/README_cn.md) · [当前基线](plan_cn.md)

这是 IsOS 实现的**唯一顺序里程碑表**，不表示 0.x 图读取器或选择器 UI 已可用。每项列出前置依赖、产出及验收门槛。[集成计划](plan_cn.md)只记录历史／当前状态；字段定义仍由 `interfaces/` 负责。本目标不引入 WorkflowService、ActionList 或 workflow DAG。已保存部署图与显式启动的独立服务是当前两种控制面。

| 里程碑 | 依赖 | 产出与验收 |
| --- | --- | --- |
| **I0 — 契约样例** | 当前 `1.0.0` 读取器和 `@v1.*` 目录 | 冻结新旧图、节点类型、包侧车、选择器、API、版本身份样例。中英文示例可解析；字段具备类型、单位、默认值、校验、所有者和扩展规则；各所有者确认边界。 |
| **I1 — 图读取器与目录** | I0 | 新图写出 `0.1.0`/`@v0.1`；安全读取现有 `1.0.0`/已知 `@v1.*`，不改原始字节或 SHA-256 修订。新增非空类型说明，旧侧车仅在显示时补默认说明；按 core/layer/group/node 提供目录。未来版本和旧任意命令节点返回带路径的迁移指引。迁移需要预览和预期修订。 |
| **I2 — 已验证软件包与选择器** | I1、注册表收据 | 安装精确验证版本，公开注册节点类型、节点集合与资源 ID。附加扩展 `node-options`；不可用已选值保留可见及原因并阻止 Apply。拒绝变化的链接内容、重复 ID、不安全路径及不兼容 EOS 适配器。 |
| **I3 — 生成配置、版本与日志** | I1–I2、EOS/EGIA setup 身份 | 从已安装默认值按修订生成不可变 EOS/EGIA 配置，秘密只用环境引用。把各核心声明的图／类型支持集合与实际图和固定包逐一比较。写有界脱敏 JSONL：一次启动摘要、状态变化、运行／关联／节点 ID、轮转与游标读取。全新环境测试证明首次使用日志顺序。 |
| **I4 — 受管生命周期及 R03 授权** | I3；EOS R02 gateway、EOS R03 验证/准入，以及各所有者的 MuJoCo 就绪 | IsOS 为每次运行签发 `egia-control`/`operator-control` 授权，并仅向受监管子进程私下传递路径。仅 EOS 注入测试授权的证据不能关闭托管 R03；IsOS 签发、轮换、停止前失败、子进程传递和干净 home 重放都必须通过。EOS 先于 EGIA 启动；就绪验证不能只靠端口。活动修订在 Restart 前不变；先停依赖方再停提供方。覆盖 MuJoCo 故障、EGIA 发现故障、重启回退、进程组后代清理和 EOS 安全停止执行器。[所有者契约](../interfaces/control-grants_cn.md)；独立服务保持在图外。 |
| **I5 — 操作界面与实际路由边** | I2–I4、IsosUI 编辑器及 EOS 路由调度 | 校验每条线的 nice 优先级与可选正 Hz，显示并编辑两值，标明仅设计边并报告队列溢出。Apply 与 Run 复核选择器 ID 和固定版本。浮动控制、监控、Vision、日志面板持久化布局，但不变成进程节点。 |
| **I6 — 集成与发行验证** | I0–I5、EGIA 阶段 | 从无需源码/npm 的全新安装环境运行 IsOS → EOS → MuJoCo → EGIA；测试故障、重启、安全停止、新旧图、日志脱敏／轮转和选择器恢复。完整输出保存 `logs/test/<run-id>/`；只发布获批 0.x 产物。保留历史 1.x 标签及已发布 wire 身份。 |

先用固定负载测吞吐量、中位数和 p99，之后才设性能目标。物理 ROS／厂商部署、`egia.tensor`、包管理的模型权重以及独立服务的图表示属于后续设计。
