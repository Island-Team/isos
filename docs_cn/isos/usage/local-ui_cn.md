# 本地管理页面

IsOS 通过自身的环回桥接服务提供轻量浏览器界面，与 Island-web 使用同一个本地 API。页面没有远程资源，也无需账号。

[English](../../../docs/isos/usage/local-ui.md)

## 打开并配对

运行 `isos ui`，打开终端输出的 `http://127.0.0.1:17600/#token=...` 链接。片段不会发送给 HTTP 服务；页面会从地址栏移除片段，仅在当前标签页内存中保存令牌。关闭标签页或停止 `isos ui` 即结束本次配对。也可打开不含片段的地址并手工粘贴终端令牌。其他端口可用 `isos ui --port 17601` 指定，随后打开输出的链接。

页面仅供连接到指定 `127.0.0.1` 端口的本地浏览器使用。API 请求仍需 Bearer 令牌。托管的 Island-web 来源及其配对流程保持可用。

## 管理部署

概览显示 EOS、EGIA 和运行节点。启动、停止按钮调用 IsOS 的受控生命周期 API；组件按钮按部署图依赖规则操作 EOS 或 EGIA。顶部可选择部署名并刷新状态。

软件包页面列出已安装记录，并搜索审核目录。点击单行查看详情。搜索结果提供 `isos packages install` 命令；此轻量界面中的安装和移除仍通过命令行执行。

配置图页面显示节点与边。可新建空图、加载所选部署、添加默认禁用的节点、编辑节点 JSON，或直接修改含边的完整配置图 JSON。应用时 IsOS 会校验并保存，错误会显示服务端的校验消息。应用不会重启运行中的节点；准备好切换快照后，请在命令行执行 `isos restart`。
