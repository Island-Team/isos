# IsOS 指南

IsOS 是 EOS 与 EGIA 的本地管理器，负责软件包库、版本化部署图和受控的 systemd 用户服务。新用户可从 [快速入门](usage/get-started_cn.md) 开始。

客户端和软件包作者请查看 [部署图](interfaces/deployment-graph_cn.md)、[发行清单](interfaces/releases_cn.md) 和 [本地管理 API](interfaces/local-api_cn.md)。现有部署请阅读 [迁移指南](maintenance/migration_cn.md)，跨仓库后续工作见 [集成路线图](maintenance/roadmap_cn.md)，贡献者请遵循 [本仓库约定](conventions_cn.md)。
