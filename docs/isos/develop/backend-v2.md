# Develop and verify the v2 backend path

[中文](../../../docs_cn/isos/develop/backend-v2_cn.md)

Build the EOS Rust bins (`aether-profile`, `aether-runtime`, `aether-http-bridge`, `aether-config-server`), IsOS, and the MuJoCo simulator. Stage the real bundle with the MuJoCo repository's `tools/build-backend-bundle.py`. `isos pkg link island/mujoco-sim 2.0.0 <bundle>` registers a local development bundle. `isos pkg install` verifies a release archive first. `isos init` writes one editable shared graph; `isos config validate` and `apply` admit and save it. Graph edits must go through the same v2 registry and IsOS package projection. Install the Aether bins beside `isos` or set `ISOS_AETHER_BIN_DIR` to their absolute build directory before generating the graph. `ISOS_AETHER_PROFILE_BIN` overrides only the validator; set `MUJOCO_ROOT` to the MuJoCo library root.

A fresh graph pins the first installed v2 MuJoCo bundle version and its first advertised scene. On 2026-10-30, an installed-command smoke check used `/home/ashex/.cargo/bin/isos` and sibling Aether release binaries with no binary override: `pkg link`, foreground `init`, `v2 validate`, `v2 apply`, and foreground `run` all passed. The four children started and Ctrl+C stopped them in dependency order. The selected scene was `pick-place`. The command and graph record is in `logs/test/20261030-starter-scene/installed-home.log`.

The IsOS source template is `templates/mujoco-graph-v2.toml`. `src/v2_starter.rs` selects local paths. `src/v2_backend.rs` resolves package receipts, descriptor and assets. `src/v2_process.rs` validates backend/device/socket references and supervises direct children. `src/http.rs` serves the workbench endpoints. EOS's registry and adapter live in its own `crates/` workspace; IsosUI owns the editor. Keep the package descriptor, graph node settings, and simulator payload structs separate.

For repeatable verification, run `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`, and `python3 tests/clean_home_v2.py`. The harness stages a protocol mock bundle in a fresh home, checks missing assets and mismatched device admission, package removal guard, process ordering, revision immutability, discovery, camera capture, base/manipulator observation and movement, safe stop, restart, and logs. It measures five start/restart cycles and 200 HTTP→EOS socket requests. It does not test MuJoCo physics or native library loading.

On Linux x86_64, 2026-10-30, the 34 IsOS tests, Clippy, and formatting passed. The clean-home mock scenario passed. Fixed-workload median/p99 startup was 346.917/350.345 ms; median/p99 HTTP→EOS request latency was 10.148/10.469 ms at 98.4 requests/s. These include the IsOS manager's 50 ms poll cadence and local Python mock. Full output is in `logs/test/20261030-isos-package-run/`.

The harness holds `isos init` and `isos run` as live processes, sends SIGINT to `run` and verifies all deployment children stop, then restarts through the API, sends SIGINT to `init`, and verifies child exit and control socket removal. Real package check (2026-10-30, Linux x86_64, MuJoCo 3.16.0): run `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`, `cargo build`, then set `ISOS_BIN`, `ISOS_TEST_REAL_BUNDLE`, `ISOS_AETHER_BIN_DIR`, `MUJOCO_ROOT`, and `ISOS_WEB_DIST` to absolute paths and run `python3 tests/real_home_v2.py`. The harness copies the real bundle into a fresh home, links it, starts foreground `init`, selects the package scene and `MUJOCO_GUI=1`, validates and applies through the workbench API, then starts foreground `run`. It verifies process order, discovery, real camera capture, base and manipulator observations and dispatch, stop, restart, logs, package removal guard, linked nested asset mutation guard, graph revision, and Ctrl+C shutdown. With `DISPLAY` and `xwininfo` available it asserts the GUI window is mapped `IsViewable`. The 34 Rust tests and real scenario passed. The two movement dispatches returned the expected `OutcomeUnknown`: the adapters confirmed acceptance but do not report terminal physical completion. One startup measured 1553.222 ms; 20 real camera captures measured median/p99 357.572/379.177 ms and 2.8 requests/s. This is an initial single-host baseline, not a target. MuJoCo emitted a nonfatal OpenGL 0x502 warning on this Wayland/X11 host; the simulator still served camera frames and control requests. Full commands and output are in `logs/test/20261030-isos-graph-audit/`.
