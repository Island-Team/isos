# MuJoCo scene and device admission

[中文](../../../docs_cn/isos/interfaces/mujoco-catalog_cn.md) · [Verified packages](package-verification.md) · [Graph](node-graph.md) · [MuJoCo owner descriptor](https://github.com/Island-Team/isos-mujoco-sim/blob/master/docs/mujoco/interfaces/package.md)

**P02 IsOS owner contract; implementation pending.** `island/mujoco-sim@0.1.1` owns the additive `backend-v2.json` catalog and its package-contributed process type. IsOS owns receipt verification, catalog admission, graph selection, revision checks, node-set composition, and the diagnostics below. EOS owns the generic camera, base, manipulator, primitive binding, and camera-gate types and the live adapters. A catalog entry supplies no actuator route or evidence that a private simulator socket is ready. P03 owns the generic `/node-options` HTTP envelope; this contract supplies only verified MuJoCo resources and availability reasons.

## Input and compatibility

The schema v4 `release.json`, P01 receipt, and `backend-v2.json` schema `2.0.0` have independent versions. The descriptor must retain exact package identity, `entrypoint`, `protocol:"mujoco-v2"`, `scenes`, `devices`, and `runtime`. IsOS obtains one exact verified package handle first; it never reads an unverified path from a graph or an option request. P01 checks release/receipt/payload/sidecar digests, regular executable and scene files, referenced asset containment, and symlink safety. A changed linked file produces P01 `package_changed` or `package_unsafe_path` before P02 semantic checks. No unrelated installed package can block a graph that does not pin it.

| Descriptor field | JSON type / unit | Purpose, validation, compatibility |
| --- | --- | --- |
| `catalog_version` | string / — | The sole P02 discriminator. Absent only for the complete historical shape; present must equal `0.1.0` with every target field. A partial mix is `mujoco_catalog_incomplete`; any other value is `mujoco_catalog_unsupported`. Neither filename nor package version implies the new shape. |
| `scenes[].id` | unique nonblank slug / — | Stable graph `settings.scene` value. The current exact IDs are `pick-place` and `navigation`; never a path. |
| `scenes[].label`, `.description` | nonblank strings / — | Display name and purpose. Both are required for a P02 descriptor. A legacy descriptor may show its ID as a read-only catalog fallback without changing its bytes. |
| `scenes[].profile` | string enum / — | Exactly `eos_benchmark_pick_place_v1` or `eos_benchmark_navigation_v1`, matching the sole supported MJCF custom numeric marker and required model elements. Use a safe XML parser and an engine load test; textual substring matching is insufficient. |
| `scenes[].path`, `.sha256` | safe relative path; lowercase 64-hex SHA-256 / bytes | The P01-verified regular MJCF file and its exact bytes. P02 checks the selected scene digest at discovery, Validate, Apply, Run, and Restart; P01's payload digest separately covers referenced assets. Do not return the path as a selector value. |
| `devices` | object of three slug IDs / — | Exactly `camera:cam-0`, `base:base-0`, and `manipulator:arm-0` for this release, with distinct IDs. The old string-map shape remains. |
| `device_catalog[]` | array of three objects / — | Exactly one entry for each `devices` kind and ID, with no extras or duplicate IDs. Each entry has nonblank `label` and `description` and a nonempty unique `scene_ids` subset of declared scene IDs. A device is available only for its selected scene. |
| `runtime.mujoco_version`, `.environment_variable`, `.library` | version, environment key, safe relative path / — | Keep `3.16.0`, `MUJOCO_ROOT`, and `lib/libmujoco.so.3.16.0`. IsOS checks the contained library at graph admission and launch; an expected filename alone does not prove loaded ABI compatibility at readiness. `MUJOCO_ROOT` is a host runtime input, not a graph selector or secret value. |

A descriptor with no `catalog_version` and no target metadata is legacy-only. It retains its previously verified `1.0.0` graph behavior and IDs, but cannot publish P02 choices or the `0.1.0` preset. Any target field without the discriminator, or any missing target field with it, fails before option or node-set publication. New semantics do not rewrite saved legacy graph bytes. The exact old and target shapes are frozen in [cross-owner fixtures](../../../tests/fixtures/scene_catalog/README.md).

## Graph and node-set admission

The package contributes `eos.process.mujoco@v0.1` at `eos/process/mujoco` and retains `eos.process.mujoco@v1.0` for verified legacy readers. The new process type has a nonblank type description; its `scene` setting has `selector:{"provider":"package","resource":"scene","package_from":"node.package"}`. It describes `socket` (owner-only Unix path), optional `env` (string table), and `start_timeout_ms` (positive integer milliseconds), plus `status` and `health` outputs with `in_process` transport and `state` data class. The process instance pins `node.package:{"id":"island/mujoco-sim","version":"0.1.1"}`. It does not save an executable or scene path. A sidecar may declare `mujoco-v2` adapter metadata but cannot claim that EOS compiled it or create an actuator/safety bypass.

The verified `sim-hardware` set composes into a `0.1.0` draft only. Its seven nodes use the contributed process type and generic EOS `@v0.1` camera/base/manipulator, base/arm primitive-binding, and camera-gate types. It requires the starter's existing `eos.dispatcher.control@v0.1` and does not duplicate it or invent an `isos.ui.vision@v0.1` identity. The `scene`, `camera_device`, `base_device`, `manipulator_device`, and `socket` parameters hold stable IDs and an owner-only socket path; defaults are `pick-place`, `cam-0`, `base-0`, and `arm-0`. IsOS injects `node.package` only for the package-contributed process type. Generic hardware instances retain `node.adapter.package` for the exact pin, `simulator_node` references, and selected `device_id` settings. Composition must validate the exact receipt, descriptor shape, selected scene/device kind and scene membership before returning a draft; it grants no launch authority. A changed scene requires revision-checked Apply and child Restart, never in-place mutation.

Validate, Apply, migration commit, Run, and Restart repeat P01 verification and P02 semantic checks for the exact pinned process and each referenced generic adapter before owner setup or child launch. IsOS checks the selected scene's declared profile, digest and referenced assets, selected device IDs against `devices` and `device_catalog`, host MuJoCo library availability, graph revision, and EOS adapter availability. Apply failure leaves saved bytes and active revision unchanged; Run/Restart failure does not replace the active child. A descriptor or graph change requires a fresh verified release or saved graph revision as appropriate. The current IsOS composer still admits only `1.0.0` and current `BackendDescriptor` rejects target fields; implementation must change both together. P03 later exposes eligible options grouped by `(node_path,setting)` without changing this admission boundary.

## Stable diagnostics

P02 retains P01's bounded `{code,path,message,id,version,stage}` diagnostic and HTTP 422 graph-admission envelope. Direct install/link/verify uses `path:""`; the fixture's `mutation.path` identifies its descriptor field. Graph-time paths below use the actual instance IDs from the candidate graph and JSON Pointer escaping. `stage` is `descriptor` for catalog metadata and `admission` for selected values or host library. Messages give a corrective reason without raw XML, absolute local paths, or environment values.

| Failure | `code` | Graph-time `path` | `stage` |
| --- | --- | --- | --- |
| Missing/partial target discriminator or field | `mujoco_catalog_incomplete` | `/cores/eos/layers/process/groups/mujoco/nodes/simulator/package` | `descriptor` |
| Unknown catalog version | `mujoco_catalog_unsupported` | `/cores/eos/layers/process/groups/mujoco/nodes/simulator/package` | `descriptor` |
| Invalid scene ID, description, profile literal, or declaration | `mujoco_scene_invalid` | `/cores/eos/layers/process/groups/mujoco/nodes/simulator/settings/scene` | `descriptor` |
| Scene profile/marker/model mismatch | `mujoco_scene_profile_mismatch` | `/cores/eos/layers/process/groups/mujoco/nodes/simulator/settings/scene` | `admission` |
| Scene digest mismatch | `mujoco_scene_digest_mismatch` | `/cores/eos/layers/process/groups/mujoco/nodes/simulator/settings/scene` | `admission` |
| Unknown selected scene | `mujoco_scene_unavailable` | `/cores/eos/layers/process/groups/mujoco/nodes/simulator/settings/scene` | `admission` |
| Invalid device map/catalog | `mujoco_device_invalid` | Affected generic node's `/adapter/settings/device_id` | `descriptor` |
| Unknown, wrong-kind, or scene-unavailable selected device | `mujoco_device_unavailable` | Affected generic node's `/adapter/settings/device_id` | `admission` |
| Missing or incompatible MuJoCo library | `mujoco_library_unavailable` | `/cores/eos/layers/process/groups/mujoco/nodes/simulator/package` | `admission` |

P01 `package_changed` at `payload` and `package_unsafe_path` at the containing stage take precedence for a sealed package. To test a semantic descriptor error, construct a candidate before receipt publication; editing a sealed descriptor must fail as P01 tampering. The [negative cases](../../../tests/fixtures/scene_catalog/negative-cases.json) freeze direct and graph-time `{code,path,stage}`, including the distinct base/arm paths and stale-revision HTTP 409. P03 may present these bounded reasons for unavailable options; it does not change the error identity.
