# IsOS guide

IsOS is the local manager for EOS and EGIA. It owns the package library, a versioned deployment graph, and scoped user-systemd processes. The [quick start](usage/get-started.md) takes a new operator from installation to an attached EOS CLI. CLI users can sign in to Island-port with GitHub Device Flow using [IsOS authentication](interfaces/authentication.md).

For package authors and client developers, see [authentication](interfaces/authentication.md), the [deployment graph](interfaces/deployment-graph.md), [release manifest](interfaces/releases.md), and [local manager API](interfaces/local-api.md). Existing deployments can follow the [migration guide](maintenance/migration.md). The [CLI release guide](maintenance/cli-release.md) covers the manual prepare and publish workflow. The [platform integration plan](maintenance/plan.md) maps ownership, command namespaces, and release gates; the [roadmap](maintenance/roadmap.md) is its short checklist. Contributors follow the [local conventions](conventions.md).
