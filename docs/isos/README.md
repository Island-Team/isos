# IsOS guide

IsOS is the local manager for EOS and EGIA. It owns the package library, a versioned deployment graph, and scoped user-systemd processes. The [quick start](usage/get-started.md) takes a new operator from installation to an attached EOS CLI.

For package authors and client developers, see the [deployment graph](interfaces/deployment-graph.md), [release manifest](interfaces/releases.md), and [local manager API](interfaces/local-api.md). Existing deployments can follow the [migration guide](maintenance/migration.md). The [integration roadmap](maintenance/roadmap.md) covers the remaining cross-repository work. Contributors follow the [local conventions](conventions.md).
